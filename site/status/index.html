What is Not Public / Not Live

What WESLR Does Not Claim

WESLR is not:

  • An AGI or conscious system
  • A sentient, self-aware, or autonomous system
  • A certified public benchmark or certification program
  • A production guarantee
  • A public marketplace
  • An unrestricted autonomous runtime
  • A publicly open chat or agent system
  • A live public runtime at chat.weslr.de for general users
  • A self-improving or autonomous self-modifying system
  • Public-science proof of any cognitive or reasoning claim

Explicitly not claimed: AGI, consciousness, sentience, self-awareness, official benchmark proof, certification, public-science proof, production-grade software, autonomous self-improvement, live public runtime.

What is not public: WESLR ChatResponder runtime is not a public service. No general-public chat signup. No public OAuth. No public user accounts. Operator authority, source-access discipline, and runtime separation are operator-gated by design.
