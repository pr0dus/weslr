Instructions & User Guide

How to use WESLR — request invite, sign in, start projects, report problems.

WESLR is currently in internal evaluation. Access is by invitation only. This guide explains the process for invited users.

Note: Public self-registration is not available. Pilot access is by invitation only. Protected routes remain password protected.

User Workflow

1. Request Invite

If you received an invitation, you can request access to WESLR. Invitations are sent to specific email addresses.

2. Sign In Only After Approval

You may only sign in to WESLR after receiving and accepting an invitation. No unauthenticated access is available.

3. Start a Project

Once signed in, you can create a new project or join an existing one. Projects maintain continuity across sessions.

4. Use Project Chat

WESLR provides a protected chat interface for project work. Messages are bounded by evidence and operator approval.

5. Correct Project Context

If context drifts, you can reset or update the project context. WESLR maintains traceable work history.

6. Report Problems

If something goes wrong, you can report the issue. WESLR's governance system tracks problems and resolutions.

WESLR is designed for continuous, traceable work with operator authority. The system does not self-approve or self-modify.

Status: Internal evaluation. Pilot access by invitation only. No public self-registration.
