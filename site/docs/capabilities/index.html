WESLR has implemented and reviewed systems where the source/docs/tests show the completed workflow: design → implementation → review → tests → commit.

This page distinguishes between:

  • Implemented in WESLR codebase — Source-backed, tested, committed
  • Publicly visible — Exposed as public interface with controlled access
  • Protected/internal — Governed by safety, operator control, or operational boundaries
