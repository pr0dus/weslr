# What is WESLR?

## Short answer

WESLR is a continuity-first cognitive AI system built to help with long-running work in a way that stays grounded, source-aware, and bounded. It is designed to preserve project context, keep memory and correction paths visible, and support careful decision-making instead of sounding like a normal chat assistant.

## Plain-language definition

WESLR helps organize work across time. It keeps track of project context, uses governed memory, and aims to make its reasoning and corrections easier to review. The goal is not just to answer once — it is to help maintain continuity across a task, a project, or an ongoing workflow.

## What makes WESLR different

A normal chatbot usually focuses on the current prompt.

WESLR is different because it is built around:

- continuity-first behavior
- governed memory
- evidence-based responses
- bounded help
- project context
- visible correction paths
- source-aware wording
- operator-approved boundaries

That means WESLR is intended to stay careful about what it knows, what it does not know, and what it should not claim.

## What WESLR is not

WESLR is not:

- a claim of AGI
- a conscious being
- certified intelligence
- a guaranteed-answer machine
- a normal open chat system
- a place for hidden prompts or secret state

It should not overclaim certainty, capability, or readiness.

## Current status

WESLR should be described conservatively as planned, preview, or not live where that is true.

Some user guidance may be available through protected invite-only preview pages, but WESLR should not be presented as open public chat or as broadly public-ready unless that has been explicitly approved.

## Who WESLR is for

WESLR is for people who want:

- structured help across longer tasks
- a system that remembers context carefully
- clearer correction and review paths
- source-aware, conservative wording
- a governed preview rather than a casual free-for-all chat
