# How to enable GitHub Discussions for CircleForge

GitHub Discussions is enabled in the repository settings on GitHub.

## Steps

1. Open the CircleForge repository on GitHub.
2. Click **Settings**.
3. In the sidebar, open **General**.
4. Scroll down to the **Features** section.
5. Check **Discussions**.
6. Save.

After that, a **Discussions** tab should appear in the repo.

## Suggested first use

Create one discussion like:
- **Title:** Looking for feedback and testers before CircleForge v0.1

Then describe:
- what CircleForge is
- what it currently does
- who would be a useful tester
- what kind of criticism or advice you want

## If Discussions is not available

Use GitHub Issues instead.
This repo now includes issue templates and draft community texts for that fallback.
