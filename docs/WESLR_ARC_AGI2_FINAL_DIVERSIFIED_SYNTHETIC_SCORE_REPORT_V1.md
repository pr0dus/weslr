## 10. Honest Limitations

1. **Synthetic benchmark only**: All tasks are generated by WESLR's internal generators. Performance on this benchmark does not measure performance on public ARC-AGI-2 tasks.

2. **Not official ARC**: This is not an official ARC-AGI-2 score. No public ARC-AGI-2 evaluation has been performed. The WESLR public ARC result remains 0/none unless explicitly run later.

3. **No generalization guarantee**: The solver may not generalize to unseen public ARC tasks. The solver uses deterministic, hand-crafted capability modules that are designed for the specific patterns in the synthetic benchmark.

4. **Benchmark families are designed by us**: The synthetic families were designed by the WESLR team. The solver was then repaired to solve them. This creates a potential circularity — the solver is evaluated on tasks it was designed to solve.

5. **Benchmark saturation**: The current benchmark is now saturated for normal synthetic families (all 25 normal families solve 100%). The remaining unsolved tasks are all adversarial (correctly rejected). Further score improvement requires new family diversification.

6. **No learned model**: The solver uses no learned model, no LLM, and no machine learning. It is a collection of deterministic capability modules with priority-based selection.

7. **No public-data tuning**: No public ARC-AGI-2 data was used for tuning or development.
