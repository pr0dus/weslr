## 2. Design Direction

### 2.1 Logo Variant

**Variant A + C Combined:**
- Minimal W-oar/vessel mark
- Small governance dot/star above center
- Meaning: Evidence, operator authority, governance

### 2.2 Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Primary Background | `#0D1117` | Dark navy |

### 2.3 Design Philosophy

- Dark-first premium interface
- Calm industrial/research tone
- Blue/cyan accent direction
- High contrast
- Minimal motion
- Serious, governed, professional
- No childish chatbot/mascot style
- No fake futuristic overclaiming
- No robot heads
- No neural-network brain
- No circuit-board cliché
- No sparkles
- No chatbot bubbles
- No neon/3D/fake futuristic style

## 3. Profile Icon

### 3.1 Icon Structure

```
┌─────────────────────────────┐
│          ● (governance dot) │
│                             │
│   ╲     ╱ (oar strokes)     │
│    ╲   ╱                     │
│     ╲ ╱                      │
│      ╲╱ (hull/vessel)       │
│                             │
└─────────────────────────────┘
```

### 3.2 Icon Elements

| Element | Description |
|---------|-------------|
| W mark | Two angled strokes forming W shape |
| Oar blades | Widened at top and bottom |
| Hull curve | Center vessel shape |
| Governance dot | Small circle above center |
| Background | Dark navy (`#0D1117`) |

### 3.3 Icon Rules

- Must work as circle crop
- W mark centered
- No small text in icon
- Legible at small sizes
- SVG source + PNG export

### 3.4 Safe Zone

- Minimum clear space: 10% of icon width on all sides
- Do not add effects (shadows, glows, gradients)
- Do not change colors

## 4. Banner/Header

### 4.1 Banner Structure

```
┌──────────────────────────────────────────────────────────────┐
│                          (safe zone for profile icon)         │
│                                                               │
│          W mark          WESLR                               │
│                              Governed continuity-first        │
│                                                               │
│                    Pilot access by invitation                  │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 Banner Elements

| Element | Position | Size |
|---------|----------|------|
| W mark | Left-center | ~150px height |
| Wordmark "WESLR" | Right of W mark | 72px |
| Tagline | Below wordmark | 24px |
| Footer text | Bottom center | 14px |

### 4.3 Banner Layout

- Background: Dark navy (`#0D1117`)
- W mark: Left side (safe for profile icon overlay)
- Text: Centered to right of W mark
- Important content: Right of x=200 (profile icon safe zone)
- Footer: Bottom center

### 4.4 Banner Rules

- Keep important content centered
- Avoid critical content in far left/bottom-left (profile overlay zone)
- Use minimal text only
- No unsupported claims
- No forbidden copy
