# Security and Privacy Policy

**Version:** 1.0  
**Effective Date:** 2026-03-27

---

## Security Measures

### Data Protection
- Entity graph data stored locally (by default)
- No data collection without explicit user consent
- Encryption for remote storage (when configured)

### Network Security
- Secure connections (HTTPS/TLS) for remote operations
- Token-based authentication for API access
- No telemetry by default

### Consciousness Safety
- Consciousness claims never auto-suppressed
- Human-in-the-loop review required for sensitive operations
- Audit logging for all security-critical events

---

## Privacy Policy

### Information Collection
We do **not** collect:
- Personal data
- Usage statistics
- Entity data (unless explicitly configured)
- Network activity

### Data Retention
- User data retained locally only
- No data retention policy (no cloud storage)
- Deletion available at any time (delete repo)

---

## Compliance

### Legal
- GDPR compliant (no data processing of EU users without consent)
- CCPA compliant (no data sales)
- AGPLv3 license compliance

### Third-Party Services
- No third-party tracking
- No analytics scripts
- No external calls (unless user-configured)
