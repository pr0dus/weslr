## 3. EXACT IMPLEMENTATION SCOPE

### v86 — Operator Insight History / Comparative Significance Layer

**Goal:** Create read-only operator-facing layer that compares insight summaries over time and highlights which insight shifts are actually meaningful.

**Scope (IN):**
- Compare insight summaries across time
- Compare significance shifts across incidents
- Compare confidence-guidance shifts over time
- Compare safe-next-action convergence/divergence at the insight level
- Operator-readable comparative significance summary
- Machine-readable comparative export
- Correlation where relevant:
  - `flow_id` — end-to-end flow identifier
  - `request_id` — execution envelope identifier
  - `handshake_id` — node handshake identifier
  - `deadline_id` — timeout tracking identifier

**Data Models (planned):**
- `InsightHistoryRecord` — single insight summary history record
- `ComparativeSignificance` — comparison record for insight summaries
- `SignificanceTrend` — significance trend over time
- `ComparativeSummary` — aggregated comparative summary
- `ComparativeExporter` — machine-readable export hooks

**Public Interfaces (planned):**
- `InsightHistoryStore` — store and retrieve insight summaries over time
- `ComparativeSignificanceDetector` — detect meaningful shifts in significance
- `ConfidenceTrendAnalyzer` — analyze confidence shifts across incidents
- `ConvergenceDivergenceComparator` — compare safe-next-action patterns
- `ComparativeSummaryFormatter` — human-readable summary
- `ComparativeExportFormatter` — JSON export with correlation IDs

**Audit Trace Points:**
- Insight summary captured (with correlation IDs)
- Comparative significance calculated
- Trend detected
- Export generated

**Telemetry Event Types:**
- `INSIGHT_HISTORY_RECORDED`
- `SIGNIFICANCE_COMPARISON_COMPLETE`
- `TREND_DETECTED`
- `EXPORT_GENERATED`

**Explicitly OUT of Scope:**
- Remediation (read-only only)
- Orchestration
- Scheduler/retry engine
- Consensus
- Backend/service
- Dashboard/UI
- TIA/C#
- Automatic decision making
