```python
def get_tia_import_record(history_path: str | Path | None = None, idx: int | None = None, source: str | None = None) -> dict | None:
    """Fetch a single TIA import record by index or source file.
    
    Returns None if not found.
    History is newest-first, so idx=1 means latest.
    Does not use limit — reads full history to ensure all records are accessible.
    """
    if history_path is None:
        history_path = Path(__file__).resolve().parent / "tia_import_history.json"
    else:
        history_path = Path(history_path)
    
    if not history_path.exists():
        return None
    
    try:
        with open(history_path, "r", encoding="utf-8") as f:
            history = json.load(f)
    except Exception:
        return None
    
    records = history.get("records", [])
    if not records:
        return None
    
    records = list(reversed(records))
    
    if idx is not None:
        if idx < 1 or idx > len(records):
            return None
        return records[idx - 1]
    
    if source is not None:
        for r in records:
            if r.get("source_file", "").endswith(source) or r.get("source_file") == source:
                return r
        return None
    
    return records[0]
```

## 4. ANY BUGS OR RISKS FOUND

### Critical Bug — Index Semantics
In `get_tia_import_record()`:

```python
if idx is not None:
    if idx < 1 or idx > len(records):
        return None
    return records[idx - 1]
```

The docstring says: **"default = latest"** and **"`--index 1` = latest"**

But the function uses **newest-first semantics** (`records = list(reversed(records))`) — so:
- `idx=1` returns `records[0]` → latest (correct)
- `idx=2` returns `records[1]` → second newest (correct)

This part is actually correct.

**Risk:** The docstring is ambiguous — it doesn't clearly explain that `idx=1` is 1-based and maps to the latest record (not index 0). This is consistent with the CLI convention (`--index 1` = latest), but the docstring could be clearer.

### Minor Risk — Source File Matching
```python
if source is not None:
    for r in records:
        if r.get("source_file", "").endswith(source) or r.get("source_file") == source:
            return r
```

This uses `.endswith(source)` which could match partial filenames (e.g., `source="export.json"` would match `tia_real_export.json`, `test_out.json` → no, because `test_out.json` doesn't end with `export.json`). But it's still fragile if multiple files share suffixes.
